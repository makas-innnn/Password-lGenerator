# 🔐 PasswordGen — Генератор паролей

Приложение на Python (Flet) для генерации надежных паролей и проверки их сложности. Собирается в APK для Android автоматически через GitHub Actions.

## 🚀 Возможности
- **Генерация паролей** (длина от 8 до 32 символов).
- **Гарантия сложности**: в каждом пароле есть буквы разных регистров, цифры и спецсимволы.
- **Проверка надежности**: встроенный анализатор показывает проценты и дает рекомендации.
- **Проверка своего пароля**: введи любой пароль и узнай его надежность.
- **Проверка на утечки**: анонимная проверка через Have I Been Pwned (только по желанию пользователя).
- **История**: сохраняются последние 5 паролей (даже после закрытия приложения).
- **Копирование в один клик**: для текущего пароля и для паролей из истории.
- **Темы оформления**: 4 готовые темы (Темная, Светлая, Фиолетовая, Лесная).
- **Поддержка языков**: русский и английский.

## 🛡️ Безопасность
Приложение работает **полностью офлайн** по умолчанию. Все пароли генерируются локально на вашем устройстве. Никакие данные не передаются на серверы разработчика. Проверка на утечки отправляет только анонимный хеш (первые 5 символов SHA-1), сам пароль не передается.

## 🛠️ Сборка APK
В репозитории настроен GitHub Actions. Любое изменение в ветке `main` автоматически запускает сборку APK.
Скачать готовый APK можно во вкладке **Actions** -> выбрать последнюю сборку -> **Artifacts**.
