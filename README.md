# 🔐 Password Generator & Analyzer

Приложение на Python (Kivy) для генерации надёжных паролей и проверки их сложности. Собирается в APK для Android автоматически через GitHub Actions.

## 🚀 Возможности
- Генерация паролей (12 и 16 символов).
- Проверка надежности в процентах (0–100%).
- Копирование пароля в буфер обмена в один клик.
- Полностью офлайн работа.

## 🛠️ Сборка APK
В репозитории настроен GitHub Actions. Любое изменение в ветке `main` автоматически запускает сборку APK.
Скачать готовый APK можно во вкладке **Actions** -> выбрать последнюю сборку -> **Artifacts**.

## 📱 Локальный запуск
`pip install kivy`
`python main.py`
